# IP 品牌库封面、词库与相关新闻增强设计

日期：2026-08-20
状态：已确认，待实施
范围：`/ipbrand` 列表页、详情页编辑态、管理员增量数据与相关新闻关联

## 1. 目标

本次增强解决四类问题：

1. 透明 PNG 封面在暗色页面中透出黑色，影响列表页识别。
2. 列表页需要在“共 N 个 IP”右侧展示平台 IP 收录标准。
3. 详情页编辑时，专业分类、出品国家/地区、受众、重点授权品类需要使用全站共用词库，避免自由输入造成值不统一。
4. 相关新闻需要真正关联“全球快讯”数据库，并支持编辑态重新匹配、跳转和删除。

## 2. 已确认的视觉与交互

### 2.1 列表页

顶部统计文字右侧紧接显示：

> 平台IP收录标准：全网粉丝2W+，且正规商业授权案例5个以上

该文字与“共 N 个 IP”使用相同颜色、字体和字号。桌面端横向排列；空间不足时换行，不能遮挡搜索框。

所有封面框先铺满白色背景，再显示原图。原图使用完整显示策略，不裁切透明 PNG 或普通图片。无封面时保留现有占位符。

右下角“案例”徽标保留位置和文案，边框与文字调整为品牌绿色；“暂无案例”沿用同一视觉体系。

### 2.2 详情页编辑态

四个字段统一使用可维护选择控件：

- 专业分类：单选下拉。
- 出品国家/地区：单选下拉。
- 受众：多选标签。
- 重点授权品类：多选标签。

受众和重点授权品类采用标签型多选视觉；相关新闻采用紧凑列表视觉。

每个字段可新增、编辑、删除词库选项。词库为全站共用，不是当前 IP 私有。

删除选项时，服务端统计当前仍关联该选项的 IP 数量。若数量大于 0，弹出提示：

> 还有 N 条信息与该选项关联，请批量调整

此时禁止删除。只有关联数为 0 时才允许删除。

### 2.3 相关新闻

编辑态相关新闻标题行增加“＋自动匹配”。点击后按当前 IP 标题和简介重新查询全球快讯，使用重新匹配模式替换当前列表，并按资讯 ID 去重；没有 ID 时按链接去重。

每条资讯仍可点击打开原资讯链接，日期右侧增加删除按钮。删除先作用于草稿，保存后持久化。

## 3. 数据架构

继续沿用现有“静态基线 + 管理员增量”模式：

- 静态基线：`public/ipbrand/ips.json`，只读。
- 管理员增量：`data/ipbrand-admin.json`，生产环境持久化到 shared data。
- 图片资产：沿用现有 IP 品牌库图片目录。

管理员增量增加全站词库和相关新闻覆盖数据。词库至少包含：

- `category`
- `place_origin`
- `ages`
- `industries`

相关新闻保存当前 IP 的管理员关联结果，包含稳定资讯 ID 和必要的展示字段，避免展示时丢失标题、日期或链接。

初始词库由当前所有合并后的 IP 记录自动汇总；管理员新增、改名和删除操作作为增量数据保存，不直接修改静态基线。

不新增 PostgreSQL 表，不改变正式站数据库架构。

## 4. 接口与服务端行为

### 4.1 词库读取

新增公开读取接口，返回四个字段各自的当前可用选项。读取时合并静态 IP 记录中的历史值和管理员词库增量，过滤已删除选项并去重。

### 4.2 词库写入

新增管理员接口，统一使用现有管理员密码校验，支持新增、改名和删除。

- 新增：去除首尾空格，拒绝空值和重复值。
- 改名：拒绝空值和同字段重复；单值字段批量替换，多值字段替换后去重；词库和 IP 增量在一次操作中同步写入。
- 删除：服务端重新加载并合并当前 IP 数据后统计关联数，不信任前端传入的数量；有任何关联返回 `409` 和准确数量；无关联才删除。
- 保存操作重新加载最新管理员增量后合并写入，避免覆盖其他管理员已经保存的数据。
- JSON 写入使用临时文件替换，避免中断留下半份文件。

### 4.3 相关新闻

沿用全球快讯查询能力，搜索标题、中文标题和简介。详情页展示态优先使用已保存的管理员相关新闻；没有管理员覆盖时实时匹配；实时匹配为空时回退原静态新闻列表。

编辑态自动匹配使用当前草稿中的中文名、英文名和简介，点击后重新查询并替换草稿列表。数据库不可用时不清空已保存资讯，显示暂时无法加载提示；无结果时显示未找到匹配资讯，并允许管理员保存为空。

## 5. 前端状态与保存

进入编辑态复制当前 IP 为 `draft`。词库选择、多选标签、相关新闻删除和自动匹配都只修改草稿，点击现有“保存修改”后整体提交。

品牌手册上传、替换、删除继续沿用现有即时生效规则。

多选标签需要支持：

- 选择已有选项。
- 删除单个已选标签。
- 防止同一字段重复选择。
- 新增词库选项后可立即选中。

单选字段需要支持清空当前值，但不能通过自由文本写入不在词库中的新值。

## 6. 异常处理

- 词库新增、改名、删除失败：保留当前编辑状态，显示服务端错误，不静默更新界面。
- 删除有关联选项：不删除，显示准确的关联数量和批量调整提示。
- 自动匹配进行中：按钮显示加载状态，阻止重复点击。
- 全球快讯数据库不可用：保留已保存资讯，不覆盖现有列表。
- 自动匹配没有结果：显示空状态，不误认为请求失败。
- 资讯重复：按 ID 去重，无 ID 时按链接去重。
- 相关新闻保存失败：保留草稿，提示重试。
- 亮色和暗色主题下，原生下拉框、选项文字和标签都必须有足够对比度。

## 7. 验收标准

### 7.1 图片与视觉

- 透明 PNG 的透明区域显示白色。
- 白底图片、普通 JPG、透明 PNG 的封面框尺寸一致。
- 图片完整显示，不被裁切。
- “案例”徽标边框和文字为品牌绿，两个主题均清晰。
- 顶部收录标准出现在 IP 数量右侧，小屏自动换行且不遮挡搜索框。

### 7.2 词库

- 四个目标字段均不再使用自由文本输入。
- 专业分类和国家/地区支持单选和清空。
- 受众和重点授权品类支持多选、去重、删除单项。
- 可新增、改名词库选项，并同步影响全站关联 IP。
- 删除有关联选项时被阻止，并显示准确的 N 条关联数量。
- 所有关联 IP 调整完成后，删除才成功。
- 刷新页面和重新进入详情页后，修改结果仍保留。
- 未登录用户不能调用词库写入接口。

### 7.3 相关新闻

- 展示态从全球快讯按标题和简介匹配资讯。
- 资讯标题点击可跳转原链接。
- 编辑态“＋自动匹配”会重新生成结果，不无限追加旧结果。
- 资讯按 ID 或链接去重。
- 日期右侧删除按钮只移除对应资讯。
- 保存、刷新和重新进入详情页后，相关新闻修改仍保留。
- 数据库暂时不可用时不清空已有已保存资讯。

3. 扩展全球快讯搜索返回结构，支持标题、简介、日期、来源和稳定 ID。
4. 改造列表页封面底色、案例徽标和顶部收录标准。
5. 改造详情页四个字段的单选/多选编辑控件。
6. 改造相关新闻编辑态自动匹配、删除和保存恢复。
7. 补充测试，执行 lint、质量测试、部署测试和本地 build。
8. 启动本地预览，等待用户确认后再进入部署流程。
